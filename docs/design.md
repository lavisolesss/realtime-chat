# 視覺設計

> 依照 [`docs/architecture.md`](architecture.md) 第 7 節「畫面清單」設計。畫面清單裡的每個元素都在下面的對照表裡。
> 可以實際操作的設計稿：[`docs/design-preview.html`](design-preview.html)（用瀏覽器直接打開）。做前端時，**樣式數值以本文件為準，版面與互動以設計稿為準**。

## 1. 方向

| 項目 | 決定 | 理由 |
|---|---|---|
| 風格 | 簡潔明亮的通訊軟體風：圓角對話泡泡，自己的訊息靠右、用主色填滿 | 大家都熟悉，不用學就會用；聊天室最重要的是好讀 |
| 優先裝置 | **手機優先**，單欄版面；容器寬度 ≥ 860px 時，右側常駐在線名單 | 匿名聊天室多半用手機打開 |
| 深色模式 | 淺色與深色都支援，跟著系統設定（`prefers-color-scheme`）自動切換 | 晚上使用比較不刺眼 |
| 專屬細節 | 每個辨識碼前面有一個**彩色小圓點**，顏色由辨識碼算出來，同一個人永遠同一色 | 兩個「小明」一眼就分得出來，對應需求共識第 7 項的防冒充 |

## 2. 設計變數（Design tokens）

所有顏色都寫成 CSS 變數，元件只能使用變數，不可以直接寫色碼。

### 2.1 顏色

| 變數 | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#EDF0F4` | `#0E131A` | 頁面與訊息列表背景、輸入框底色 |
| `--surface` | `#FFFFFF` | `#18202A` | 頂部列、輸入區、別人的泡泡、對話框、在線名單 |
| `--surface-2` | `#E2E7EE` | `#222C38` | hover 背景、停用按鈕 |
| `--fg` | `#17202B` | `#E6EBF1` | 主要文字 |
| `--muted` | `#5A6576` | `#9AA6B5` | 次要文字：時間、辨識碼、計數器、分隔線文字 |
| `--line` | `#D2D9E2` | `#2B3644` | 邊框、分隔線 |
| `--accent` | `#2546B5` | `#8AA4FF` | 主色：自己的泡泡、送出按鈕、連結、焦點外框 |
| `--on-accent` | `#FFFFFF` | `#0A1022` | 主色上的文字 |
| `--accent-soft` | `#DDE5FB` | `#1E2949` | 示範模式橫幅背景 |
| `--warn-bg` / `--warn-fg` | `#FFF0D2` / `#6E4300` | `#3A2A09` / `#FFD48A` | 斷線橫幅、「送太快了」提示 |
| `--danger` / `--danger-soft` | `#B42318` / `#FCE3E0` | `#FF8B7B` / `#3A1714` | 刪除按鈕、錯誤文字、超過字數 |
| `--scrim` | `rgba(15,20,27,.42)` | `rgba(0,0,0,.6)` | 對話框和側欄後面的半透明遮罩 |
| 在線綠點 | `#1F9D55` | 同左 | 「N 人在線」前的小圓點 |

**辨識碼顏色：** `oklch(var(--tag-l) var(--tag-c) H)`，其中 `H = parseInt(tag, 16) % 360`。
淺色 `--tag-l: 55%; --tag-c: .15`，深色 `--tag-l: 74%; --tag-c: .13`。每個 `.tag` 元素用 inline style 設定 `--h`。

**深色模式的 CSS 寫法：** 淺色值寫在 `:root`；深色值寫在 `@media (prefers-color-scheme: dark) { :root { … color-scheme: dark } }`。`body` 一定要設定 `background: var(--bg)`。

### 2.2 字型

從 Google Fonts 載入，每一種都要有備用字型：

| 變數 | 字型 | 用在哪裡 |
|---|---|---|
| `--font-display` | **LXGW WenKai TC**（霞鶩文楷，700） | 只用在聊天室名稱「匿名聊天室」和空狀態標題。手寫感，讓匿名聊天室帶一點溫度 |
| `--font-body` | **Noto Sans TC**（400 / 500 / 700） | 其他所有文字 |
| `--font-mono` | **JetBrains Mono**（500） | 辨識碼、時間、字數計數器，數字對齊（`tabular-nums`） |

備用字型：`"PingFang TC", "Microsoft JhengHei", system-ui, sans-serif`（等寬字型用 `ui-monospace, Consolas, monospace`）。

### 2.3 字級、間距、圓角

| 類別 | 值 |
|---|---|
| 字級 | `--text-xs: .75rem`（時間、辨識碼、提示）、`--text-sm: .8125rem`（暱稱、按鈕）、`--text-md: .9375rem`（訊息內文）、`--text-lg: 1.125rem`（聊天室名稱、對話框標題）、`--text-xl: 1.375rem` |
| 行高 | 內文 1.6 |
| 間距 | 4 / 8 / 12 / 16 / 24 px（`--space-1` ~ `--space-5`）。左右邊距固定 16px |
| 圓角 | 泡泡 18px（說話者那一側的上角 6px，像對話框的尾巴）、按鈕與輸入框 12px、對話框 16px、膠囊按鈕 999px |
| 陰影 | 只用在浮在上層的東西：對話框、手機側欄、「↓ 有 N 則新訊息」 |

## 3. 版面結構

```
┌──────────────────────────────────────┐
│ 匿名聊天室        [匿名水獺 ●#a3f9] [● 5 人在線] │ ← 頂部列（surface）
├──────────────────────────────────────┤
│ 示範模式 訊息只存在你的瀏覽器…              │ ← 橫幅（只在需要時出現）
├──────────────────────────────────────┤
│            已經是最早的訊息                │
│ ──────── 10 月 13 日 ────────           │
│ 小明 ●#5d08 09:15                       │
│ ╭────────────────╮                      │ ← 別人：靠左、surface
│ │大家期中考準備得怎樣│                      │
│ ╰────────────────╯                      │
│                  匿名水獺 ●#a3f9 09:22  │
│                    ╭──────────────╮     │ ← 自己：靠右、accent
│                    │謝啦，我晚點看  │     │
│                    ╰──────────────╯     │
│                        （已編輯）編輯 刪除 │
│              [↓ 有 3 則新訊息]           │
├──────────────────────────────────────┤
│ ┌────────────────────────┐ [送出]       │ ← 輸入區（固定底部）
│ │說點什麼…               0 / 500│        │
│ └────────────────────────┘             │
└──────────────────────────────────────┘
```

- 整個 App 是一個四列的 grid：頂部列、橫幅、訊息區（`1fr`，可捲動）、輸入區。
- 高度用 `100dvh`，手機鍵盤彈出時輸入區不會被擋住；輸入區底部加上 `env(safe-area-inset-bottom)`。
- **寬螢幕（≥ 860px）：** 訊息區變成兩欄，`minmax(0,1fr) 260px`，右側常駐在線名單，這時不顯示名單的關閉按鈕。
- **窄螢幕：** 在線名單是從右側滑出的抽屜（寬 `min(300px, 86%)`），後面有遮罩。
- 訊息泡泡最大寬度 `min(80%, 34em)`；長網址用 `overflow-wrap: anywhere` 換行。

## 4. 畫面清單對照（架構文件第 7 節）

### 4.0 進入畫面

整頁 `--bg` 底，中間一張卡片（寬 `min(400px, 100%)`、`--surface` 底、1px `--line` 邊框、圓角 16px、淡陰影），上下左右置中。卡片內由上而下：標題「匿名聊天室」（`--font-display` 700、1.5rem）→ 說明文字（`--text-sm`、`--muted`）→ 標籤列：左「你的代號（1～20 字）」、右「隨機產生」（透明按鈕、主色字）→ 輸入框（與改暱稱視窗同樣式，右側內嵌「0 / 20」）→ 錯誤文字 → 滿寬主色按鈕「進入聊天室」。不合規定時按鈕停用；送出中改成「進入中…」。還沒打字前不顯示紅字錯誤。

### 4.1 主畫面

| 架構文件元素 | 設計 |
|---|---|
| 聊天室名稱 | 「匿名聊天室」，`--font-display` 700、`--text-lg` |
| 我的暱稱＋辨識碼 | 膠囊按鈕：暱稱（過長截斷成…，最多約 9 字寬）＋彩色點＋`#a3f9`。點了打開改暱稱視窗 |
| 「目前 N 人在線」 | 膠囊按鈕：綠點＋「5 人在線」。點了打開在線名單（寬螢幕時名單已常駐，按鈕仍保留） |
| 示範模式橫幅 | `--accent-soft` 底，粗體主色「示範模式」＋「訊息只存在你的瀏覽器，不會傳給其他人」。不能關閉 |
| 連線狀態橫幅 | `--warn-bg` 底、`--warn-fg` 字，前面一個轉圈圖示＋「連線中斷，正在重新連線…」，`role="status"` |
| 頂端「載入中…」／「已經是最早的訊息」 | 置中小字 `--muted`；載入中前面有轉圈圖示 |
| 日期分隔線 | 置中「10 月 13 日」，兩側細線延伸到邊 |
| 每則訊息 | 上方 meta 列：暱稱（`--text-sm` 500）、彩色點＋`#辨識碼`（mono）、時間（mono）、「（已編輯）」。下方是泡泡 |
| 網址連結 | 底線、別人泡泡裡用 `--accent`、自己泡泡裡用繼承色；`target="_blank" rel="noopener noreferrer nofollow"` |
| 自己訊息的「編輯」「刪除」 | 泡泡下方的小文字按鈕。電腦：hover 或鍵盤焦點時才出現；手機：點一下訊息後出現。「刪除」hover 時變紅 |
| 「↓ 有 N 則新訊息」 | 浮在訊息區底部中央的主色膠囊，有陰影 |
| 空狀態 | 置中：「還沒有人說話」（display 字型）＋「來打個招呼吧！」 |
| 多行輸入框 | 圓角 12px、`--bg` 底；自動長高，最多 5 行後捲動。placeholder「說點什麼…（Enter 送出，Shift＋Enter 換行）」 |
| 字數計數器 | 輸入框右下角「123 / 500」，mono；超過 500 變 `--danger` |
| 送出按鈕 | 主色實心「送出」；停用時 `--surface-2` 底、`--muted` 字 |
| 提示文字 | 輸入框上方的小標籤，`--warn-bg` 底，例如「送太快了，請稍等」，幾秒後消失 |

### 4.1.1 訊息保存提示

輸入列下方一行小字（`--text-xs`、`--muted`）：「訊息會公開保存在伺服器上 30 天（最多最新 5,000 則），之後自動刪除。請勿張貼個人資料。」進入畫面也在卡片最下方（上方一條 `--line` 細線隔開）顯示同一段。示範模式不顯示。

### 4.2 改暱稱視窗

置中對話框（寬 `min(360px, 100%)`），標題「改暱稱」→ 輸入框（右側內嵌「4 / 20」）→ 錯誤文字（「暱稱不能是空的」／「暱稱最多 20 個字」）→ 說明「你的辨識碼 ●#a3f9 不會改變，別人靠它分辨你。」→ 右下「取消」（透明）「儲存」（主色）。不合規定時「儲存」停用。Enter 儲存、Esc 取消。

### 4.3 在線名單

標題「目前 5 人在線」＋關閉按鈕（×）。每人一行：暱稱＋彩色點＋辨識碼；自己排第一並加上主色「（你）」。

### 4.4 刪除確認視窗

標題「刪除訊息」→「確定要刪除這則訊息嗎？刪除後無法復原。」→「取消」（透明）＋「刪除」（`--danger` 實心）。

### 4.5 編輯模式

原本的泡泡換成一個有主色 2px 外框的編輯框：多行輸入 → 下方一列「字數計數器｜取消｜儲存」。內容沒變、空白或超過 500 字時「儲存」停用；Esc 取消。

## 5. 狀態與互動

| 狀態 | 畫面變化 |
|---|---|
| 送出後 1 秒內 | 送出按鈕停用；這時再按送出或 Enter，顯示「送太快了，請稍等」 |
| 斷線 | 顯示連線狀態橫幅；送出、編輯、刪除停用；輸入框文字保留 |
| 往上看舊訊息 | 新訊息進來不自動捲動，改顯示「↓ 有 N 則新訊息」 |
| 載入更早訊息 | 補在上方後維持原本的捲動位置 |
| 對話框開啟 | 後面加遮罩；點遮罩或按 Esc 關閉；開啟時焦點移到第一個輸入框 |
| 動畫 | 只有轉圈圖示和操作按鈕淡入；`prefers-reduced-motion` 時全部關掉 |

## 6. 無障礙與實作提醒

- 所有可以點的東西都是 `<button>`，鍵盤焦點用 2px 主色外框（`:focus-visible`）。
- 訊息列表加 `aria-live="polite"`；對話框加 `role="dialog"`／`"alertdialog"` 與 `aria-modal`。
- 使用者內容一律用 `textContent` 顯示，只有網址用程式建立 `<a>` 元素（設計稿裡的 `renderText()` 就是範例）。**不可以用 `innerHTML` 顯示使用者內容。**
- 字數用「字元」計算（`[...text].length`），emoji 算 1 個字。
- 中文輸入法選字時按 Enter 不送出（檢查 `event.isComposing`）。
