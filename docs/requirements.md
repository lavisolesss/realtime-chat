# 需求說明

## 我想做什麼

一個匿名的即時聊天室網頁。打開網址就能進去聊天，不用註冊帳號。

## 使用者可以做的事

- 打開網頁就進入聊天室
- 輸入一個暱稱（不填也可以，系統給一個隨機名字）
- 送出文字訊息
- 即時看到其他人送出的訊息，不用重新整理頁面
- 進來時可以看到最近的聊天紀錄

## 我已經知道的技術方向

- 用 Supabase 存訊息
- 用 WebSocket 做即時傳訊
- 網頁放在 GitHub Pages 上給別人看
- 程式碼放在 GitHub repo：`realtime-chat`

## 我還不知道的（交給 Claude Code）

- Supabase 要怎麼設定
- 前端要用什麼語言、什麼框架
- 程式要怎麼寫
- 金鑰怎麼產生、要放在哪裡

## 先不做的

- 帳號註冊與登入
- 多個聊天室
- 傳圖片或檔案
